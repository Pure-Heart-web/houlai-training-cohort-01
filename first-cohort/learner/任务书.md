# 学员任务书
**模拟训练｜东澜流体设备有限公司及全部资料虚构**

你是猴来工作室新成员。虚构客户发送工业询盘，团队收到邮件、历史表和两个版本技术资料。你的任务是核验信息、提出澄清问题并向下一岗位交接；不做泵选型、材料适用性或价格判断，不发送真实邮件。

每一天 150 分钟；计时见七日安排。每天先独立写出认识，随后可用 AI，再关闭 AI 用自己的语言表达，最后实际行动并留证。可使用文本、表格、纸笔或不同 AI；没有模型时使用四份模拟答案比较，记录工具和限制。仅在明确标为独立考核的时段限制 AI。不得照抄 AI 作为自己的结论；逐条核对来源并能解释。

提交：每日初始认识与最高帮助等级；自行设计的 Prompt Map 和至少两份答案比较；来源核验表、问题清单；自己的 Minimum Understanding Package 与 Minimum Action Card、执行证据；岗位产出与检查记录；Delivery & Acceptance Package；答辩及复盘。按公开评价表打分，关键条件未满足须补做；高分不自动代表独立掌握。素材和考试要求见本包，禁止接触导师私有材料。

记录每条事实的文件与位置；将事实、推断、待确认分开。对不同资料之间差异及单位问题说明依据、处理和下一步，不把空值当零。

V2 可在 [训练台](../console/index.html)填写（须按 README 启动本地服务）。提交结构见 [提交包模板](../templates/提交包.md)。Day 5 是公开限时练习，Day 7 才是未见独立考核。
