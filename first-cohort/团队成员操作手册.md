# 猴来工作室第一期培训｜团队成员操作手册

**模拟训练｜适用对象：创始人、导师、培训组织者及技术／实施／交付学员｜版本 1.0｜2026-10-31**

本手册用于组织《从 AI 使用者到独立交付者——工业询盘核验实战训练》。东澜流体设备有限公司及相关人物、邮件、数据均为虚构。七天每天建议 150 分钟；训练以个人认识和实际产物为核心，填写数量不等于掌握程度。

## 先找到自己的部分

| 成员 | 主要职责 | 先阅读 |
|---|---|---|
| 创始人／负责人 | 确定人员和安排，检查开营条件，参与答辩和验收 | 本手册“创始人”部分、[开营验收](开营与验收.md) |
| 导师 | 讲解、观察、提问、复核证据、评分和反馈 | 本手册“导师”部分、[导师公开操作](operations/导师公开操作.md) |
| 培训组织者／班主任 | 分发资料、安排时间、收齐成果、跟踪反馈 | 本手册“培训组织者”部分 |
| 每位学员 | 独立思考、使用训练台、执行岗位任务、提交并解释 | 本手册“学员”部分、[学员任务书](learner/任务书.md) |
| 技术、实施、交付学员 | 完成本岗位产物并与其他岗位交接 | 本手册“三条岗位路径”部分 |

人数较少时，同一人可以兼任创始人、导师或组织者；需要在每份验收记录中写清实际复核人。学员不能把自己的填写或同伴口头鼓励记录为导师已验收。

## 一、所有人共同遵守的工作顺序

1. **先独立思考**：阅读场景，自己写任务目标、已知事实、推断和问题；保存原始认识快照。
2. **设计 Prompt Map，比较观点**：写目标、背景、输入来源、约束、输出、核验方法及提问顺序；可以选择 AI 工具，也可以比较模拟 AI 答案。
3. **脱离 AI，独立表达**：用自己的语言写最小理解包，解释问题、例子、证据、边界和未知；标明对 AI 观点的采纳或否决理由。
4. **行动、验证、交付、复盘**：填写最小行动卡并实际执行，保留产物、检查证据、未决事项和下一步。

所有事实写来源位置；未知写待确认，不自行补造。允许使用不同工具和方法，不要求付费模型或 API。每天如实记录最高帮助等级：H0 为不影响解题方向的工具性查询或独立完成；H1 有方向性提示但本人完成关键判断；H2 有关键思路、规则、代码或明显纠错；H3 为 AI 完成主要成果、本人主要检查整理。详细定义见 [帮助等级](learner/帮助等级.md)。

公开资料可开展练习。正式未见题独立考核仍须完成私有资料迁移、导师审题以及独立学员账户访问验证；具体准备状态由授权导师核验。正式独立考核仅允许 H0；出现方向性提示即转为练习，并在新变体上复现。

## 二、创始人／负责人怎么操作

### 开营前

1. 明确成员、各自岗位、导师、培训组织者、每日时间、提交渠道和截止时间；首期可按三名学员分别选择技术、实施和交付示范。
2. 指定导师与接收人，确认每人能访问公开学员包并导出成果。只分发本公开仓库的学员资料或专用学员 ZIP；不得向学员分发导师私有题库。
3. 与导师过一遍 [开营与验收](开营与验收.md)：公开练习可以开展；正式未见考核必须先核实私有资料和权限。不要将导师答案或考题放进学员包。
4. 安排 Day 7 答辩资源：20 分钟是**每人**时间；多人需多名评审并行，或另行安排补充时间。

### 培训中

- 每天收看导师的简短进度：谁完成、谁卡住、缺少什么证据、下一步由谁做；不以是否填满训练台作为判断。
- Day 4 检查三岗交接是否有明确接收人；Day 5 抽看一份真实产物及测试或复核证据；Day 6 观察模拟交接是否有人能接手。
- 如果成员记录 H2/H3，把它视为学习过程；不据此宣布其已经独立掌握。

### 答辩和结营

1. 先请成员不看 AI 说明任务目标、关键判断、依据和边界。
2. 追问一个条件变化或反例：“如果这项信息缺失／规则改变，你会怎样处理？”记录成员的实际回答。
3. 查看真实产物、证据和未决项，再与导师一起填写评分记录：总分 100，80 分为建议线；关键项有一项不合格则补做。
4. 明确结果：本次练习达标、需补做，或独立能力证据不足。能力等级须按 [帮助等级](learner/帮助等级.md)及仓库能力等级规则另行判断。
5. 征得成员同意后，选择可复现的方法，由另一人试用并记录边界，再按 [优秀方法模板](methods/方法收录模板.md)收录。

## 三、导师怎么操作

### 每天开场

1. 确认当天目标、时长、提交时间和当前是“练习”还是“独立考核”。公开案例用于练习；不要把见过的题当未见变体。
2. 提醒先独立写认识。Day 1 用漫画逐格讲解：每格先请成员写或说自己的看法，再组织讨论；不要提前给完整答案。
3. 明确何时可以用 AI。练习中导师和 AI 的方向性帮助均按实际记录；如果独立考核得到方向性提示，将该次转为练习。

### 每天收尾

1. 收集学员导出的 JSON、Markdown，以及岗位实际产物、验证证据和 [提交索引](templates/提交包.md)。训练台不会替导师自动收作业。
2. 对照当天目标检查完成情况；抽查原始认识、Prompt Map、AI 观点取舍、理解包、行动卡与产物是否相互对应。
3. 问“你为什么这样判断？依据在哪里？哪里仍不确定？”先让本人解释；证据不足记为待补，不补造通过。
4. 每人至少给出一条具体反馈和一个下一步，写清负责人及时间。需要评分时使用 [评分记录](assessment/导师评分记录.md)；具体复核步骤见 [导师公开操作](operations/导师公开操作.md)。

### Day 7 特别安排

私有隔离门槛满足、导师已审阅未见合成题后，按 20 分钟信息判断、60 分钟岗位实操、10 分钟休息、每人 20 分钟答辩、40 分钟复盘组织。人数多于评审容量时，额外排一对一答辩，不压缩为全组共用 20 分钟。未满足私有条件时，Day 7 改做公开练习和答辩演练，不记录为正式未见独立考核。

## 四、培训组织者／班主任怎么操作

### 开营前检查

- [ ] 确认学员名单、训练代号、岗位、导师和接收人；确定每日 150 分钟的时段及提交方式。
- [ ] 向每位成员分发独立学员包，确认他们有电脑、Python 3.9+、浏览器；技术岗另需 Git。没有付费模型也可使用模拟答案。
- [ ] 让成员各自在设备启动本地服务并打开训练台；说明 `127.0.0.1` 指**当前这台设备**，不是团队共享地址。
- [ ] 确认每人可以保存和导出；通知学员每天自行保存 JSON／Markdown 及实际产物，浏览器或设备之间不会自动同步。
- [ ] 登记 Day 7 评审人和一对一时间；私有考试条件未完成时在日程中明确标注“练习”。

### 每日跟进表（复制后填写）

| 日期/学员代号 | 岗位 | 当日目标 | 提交位置 | 已收材料 | 阻塞及需要谁协助 | 导师反馈/截止时间 |
|---|---|---|---|---|---|---|
| | | | | | |

组织者只记录实际收到的材料；不代学员编写个人认识，也不代导师判定成绩。发现缺项时通知成员补交，由导师判断质量。

## 五、每位学员怎么操作

### 第一次打开训练台

1. 解压导师发放的学员包。打开终端，进入解压后的 `first-cohort` 目录，执行：

   ```bash
   bash tools/start_training.sh
   ```

   在**同一台电脑**浏览器打开 `http://127.0.0.1:8765/console/`。如果端口被占用，执行 `bash tools/start_training.sh 8766`，并打开 `http://127.0.0.1:8766/console/`。以上脚本适用于 Mac／Linux；其他环境请与组织者确认运行方式。
2. 左侧选择当天，填写训练代号、岗位和“练习”；每日完整目标查看 [七日安排](learner/七日安排.md)。
3. 第一关先写“我认为真正的问题”和“事实／未知”，然后点击 **保存原始认识快照**。后面改变想法时，将变化写进自己的判断，保留原始认识。
4. 第二关自己设计 Prompt Map，再比较至少两份观点并写来源、采纳／否决或待核实。可以选用 AI，也可以使用模拟 AI 观点。
5. 第三关关闭 AI，用自己的语言写判断和最小理解包；第四关写行动卡，并填写真实执行结果、产物位置、验证和复盘。
6. 选择本次最高 AI 帮助等级，填写具体帮助；点击 **保存草稿**。浏览器自动保存也仅限当前浏览器与网址，换端口、换设备或清理数据可能看不到旧草稿。
7. 当天结束点击 **导出 Markdown** 和 **导出 JSON**，把实际岗位文件、测试／检查证据和索引一起提交。需要恢复时，使用 **导入已有 JSON**；导入会覆盖对应日的浏览器草稿，先备份。

网页显示“表单填写完成”或导出格式通过，只表示记录已填写／格式可读，不能代替导师对产物和理解的验收。快照时间来自设备，不是监考证明。

### 第一天怎么安排

| 时间 | 你要做的事 | 留下什么 |
|---|---|---|
| 0–25 分钟 | 独立读任务和资料，写目标、已知、未知及至少 3 个问题，保存快照 | 原始认识 |
| 25–45 分钟 | 跟随导师看漫画，先独立回答，再参与讨论 | 自己的观点和问题 |
| 45–70 分钟 | 设计 Prompt Map，比较 AI 或模拟答案 | 地图、观点和待核验来源 |
| 70–100 分钟 | 关闭 AI，自己解释理解和边界 | 最小理解包 |
| 100–140 分钟 | 执行行动卡，回查至少一处原文 | 实际动作、来源、证据和未决项 |
| 140–150 分钟 | 复盘、记录帮助、导出提交 | JSON、Markdown 及产物／证据 |

### 每次提交前自查

- [ ] 原始独立认识和记录时间；Prompt Map；AI 观点筛选或未用 AI 的说明。
- [ ] 自己的最小理解包和最小行动卡；实际产物及位置；验证证据和未决项；个人方法复盘。
- [ ] 本次最高帮助等级和具体帮助；事实、推断、待确认区分清楚。
- [ ] 接收人能打开所列文件；未执行、未通过或未接收的内容如实标记。

可按 [提交包模板](templates/提交包.md)整理。当天做不完如实记录阻塞和下一步，不用编造完成。

## 六、三条岗位路径：各做什么、交什么

### 技术成员

**任务：**在独立训练副本完成 [技术 Issue](technical-lab/ISSUE.md) 的基础数值比较函数。先阅读 Issue 和起始代码，自己分析输入、输出及边界，比较方案；再在个人副本建立 Git 分支、运行公开测试并保留初始 RED，修改后运行 GREEN 与补充回归。禁止删除测试、修改预期或硬编码样本求通过。

**提交：**代码、原公开测试、RED／GREEN 输出、补充回归证据、本地 PR 记录、四类业务练习台账及最高帮助记录。**导师检查：**能在干净副本复现、测试未被篡改、本人能解释关键分支和限制；正式独立复核另需导师私有未见测试与答辩。完整步骤见 [技术线](roles/技术线.md)。

### 实施成员

**任务：**阅读模拟邮件、版本资料和历史表，建立字段规则与来源台账。覆盖正常、冲突、单位歧义、缺失四类练习；将计算结果、判断条件和待确认事项分开。

**提交：**[实施台账](templates/实施台账.csv)、四类检查的输入／预期／实际／证据、不少于 4 个包含来源和影响的澄清问题，以及一封**不发送**的模拟客户邮件。**导师检查：**逐项能定位资料、问题有确认对象与下一步、未做无依据的选型或价格等判断。完整步骤见 [实施线](roles/实施线.md)。

### 交付成员

**任务：**把核验工作拆成至少 4 个任务，明确责任角色、输入／输出、依赖、相对训练日截止时间、验收条件、风险和升级时机；记录实际进度，组织同伴交接。

**提交：**[交付台账](templates/交付台账.csv)、成果检查清单、风险／问题记录、模拟交接及接收或退回反馈。**导师检查：**依赖和负责人清楚、记录有实际证据、接收人能找到资料并继续处理；没有同伴接收时写“待复核”。完整步骤见 [交付线](roles/交付线.md)。

## 七、七天协作与交接

| 天 | 共同目标 | 导师／组织者 | 学员提交 |
|---|---|---|---|
| Day 1 | 认识场景，先独立表达 | 带看漫画，收初稿和问题 | 初始认识、至少 3 个问题、一次原文核对 |
| Day 2 | 自行设计提问并比较观点 | 检查来源和取舍 | Prompt Map、至少两份观点比较及一处分歧核验 |
| Day 3 | 独立形成理解并行动 | 询问自己的例子、检查行动 | 理解包、行动卡和实际结果或阻塞 |
| Day 4 | 拆分岗位任务与依赖 | 确定交接对象 | 个人工作包、输入输出和验收条件 |
| Day 5 | 公开题 60 分钟岗位实操 | 核对专业产物与验证 | 岗位产物、正常／冲突／单位歧义／缺失检查证据 |
| Day 6 | 模拟交付、接收和反馈 | 观察交接并记录退回／接收 | 交付包、接收反馈、遗留与方法复盘 |
| Day 7 | 符合条件时进行未见考核与答辩 | 核查私有门槛、分配评审 | 考核证据、个人解释与能力档案；未满足条件则为练习记录 |

**模拟交接例子：**实施成员把带来源的字段台账交给技术成员；技术成员说明函数验证范围和未覆盖的业务判断；交付成员检查产物、依赖、未决事项及接收人。每个人仍需保留自己的认识、行动和证据，交接不能替代个人作业。

## 八、遇到问题找谁

| 情况 | 先怎么做 | 找谁 |
|---|---|---|
| 训练台打不开或端口占用 | 确认在本机启动服务、网址与端口一致；保留错误信息 | 培训组织者／技术支持 |
| 草稿看不到 | 核对是否换浏览器、设备或端口；尝试导入此前导出的 JSON，导入前备份 | 培训组织者 |
| 不知道资料如何判断 | 写出已知来源、自己的疑问和影响；练习时可请求提示并记录帮助 | 导师 |
| 代码测试失败 | 保存原始输出，定位失败后修改；不要改测试预期掩盖问题 | 技术导师／同伴，记录帮助 |
| 资料缺失或相互冲突 | 原样记录来源和待确认事项，不自行补值 | 导师；必要时拟写模拟澄清问题 |
| 私有考题或权限不确定 | 暂停正式独立考试，改做公开练习 | 创始人／授权管理员 |
| 作业尚未完成 | 写明已做、阻塞、证据及下一步 | 导师和接收人 |
