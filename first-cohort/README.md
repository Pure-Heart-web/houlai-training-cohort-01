# 第一期训练包 V2：从 AI 使用者到独立交付者
**模拟训练｜东澜流体设备有限公司等全部资料虚构｜2026-10-31｜制作帮助 H3**

本公开仓库包含可分发的学员训练资料，所有案例均为模拟训练。管理员可在仓库根目录执行 `python3 -B first-cohort/tools/make_learner_package.py` 生成学员 ZIP。

按角色开展培训请先看 [团队成员操作手册](团队成员操作手册.md)：包含创始人、导师、培训组织者及三条岗位路径的操作与交付。

## 开始训练
在本仓库根目录执行：
```bash
python3 first-cohort/tools/check_training.py first-cohort
bash first-cohort/tools/start_training.sh
```
打开 [训练台](http://127.0.0.1:8765/console/)。端口被占用时用 `bash first-cohort/tools/start_training.sh 8766`，打开对应端口。复制独立学员包后，也可以在包目录执行 `bash tools/start_training.sh`。Python 3.9+，无第三方库或付费模型要求；浏览器需要允许当前站点存储。CSV、Markdown 在训练台资料查看器中可读，原文件可下载。只直接双击 HTML 不能保证读取资料或草稿行为。

1. 阅读 [任务书](learner/任务书.md)、[七日安排](learner/七日安排.md)、[漫画分镜](learner/漫画分镜.md)及[帮助等级](learner/帮助等级.md)。
2. 填学员代号、岗位、任务性质；先独立写认识与事实/未知，保存原始快照，再画 Prompt Map、筛选 AI 或四份模拟答案、关 AI 写理解包、执行行动并复盘。
3. [模拟资料](inputs/模拟资料.md)、[历史表](inputs/历史Excel.csv)为公开练习输入。技术、实施、交付任选 [岗位任务](roles/岗位任务.md)；用 [工作模板](templates/工作模板.md)记录外部实际产物。
4. 草稿随输入保存于当前浏览器与来源，清理浏览器或换端口/设备不会自动迁移。每日导出 JSON 和 Markdown；需迁移时导入 JSON，先验证再确认覆盖对应日。未填完也允许导出，不代表验收合格。
5. 将导出文件和实际产物一起交给导师；个人提交包括原始认识、Prompt Map、AI 筛选、理解包、行动卡、产物、验证证据、方法复盘。结构见 [提交包](templates/提交包.md)。

## 组织与验收
每天 150 分钟，训练台计时为其中个人片段；Day 5 为公开限时岗位练习，Day 7 为未见题独立考核。按 [Day 1 与 Day 5 现场流程](operations/Day1与Day5流程.md)、[导师公开操作](operations/导师公开操作.md)、[100 分公开评价](assessment/公开评价.md)和[评分记录](assessment/导师评分记录.md)组织。填写数量和测试通过均不单独证明理解。

[开营清单](开营与验收.md)列实际开营条件；正式未见题独立考核须由导师先完成私有材料准备、审题和独立学员账户访问验证；未满足时仅可开展公开练习。操作要求见 [私有资料接入](operations/私有资料接入.md)。学员包不含答案/隐藏测试。

本公开版本只包含学员材料及公开操作说明。优秀方法经同意并复现后存入 [方法区](methods/方法收录模板.md)。无网络可用本地 Issue/PR 记录；不自行创建远程仓库、推送或部署，不联系真实客户。
