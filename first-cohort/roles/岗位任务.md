# 三岗位共用方法与专业验收
**模拟训练｜D4 拆任务、D5 公开限时实操、D6 交接、D7 未见题考核。**

共同方法：先独立认识并保留原文，再设计 Prompt Map，比较并验证 AI 观点，关 AI 写理解包，执行行动卡，提交实际产物、证据及复盘。每日按最高帮助等级记录；公开练习 H0–H3 均可，独立考核仅 H0。

- [技术线](技术线.md)：本地受控 Issue → 分支 → RED/GREEN → 回归 → 代码和 PR/本地交付。
- [实施线](实施线.md)：字段规则 → 冲突/歧义/缺失样本 → 来源定位 → 可执行验收。
- [交付线](交付线.md)：任务拆解 → 依赖/进度/风险 → 成果检查 → 模拟交接。

提交结构使用 [提交包](../templates/提交包.md)；各岗均覆盖公开 N/C/U/M 四卡，技术岗可另附业务台账，函数不代替业务判断。共同评分见 [公开评价](../assessment/公开评价.md)，岗位检查决定专业维度是否有证据。未经确认不作选型、材料适用性或价格承诺。
