# AI 辅助学习 Prompt Map — Simulation

每次顺序：①先独立思考并留下时间顺序可辨的初稿；②选择提示词提问；③记录关键建议和最高帮助等级；④至少质疑两项具体建议，写原因、核验来源和采纳/拒绝/待确认；⑤用自己的语言写最终结论。AI 是教练，不代写最终答卷；不得上传真实数据或密钥，不使用真实模型 API。无可用 AI 时保留独立初稿和拟问问题，AI 步骤标记 NOT_EXECUTED，不得虚构对话。

共同前缀：`这是 Simulation。请只提出问题、检查思路和指出可能遗漏，不要代写最终交付；区分已知、推断和未知。我的初步判断是：[学员填写]；依据：[填写]。`

## A 技术 Prompt Map

| 阶段 | 提示词（接共同前缀） | 学员核验 |
|---|---|---|
| 数据流 | 请对我画的数据流提三个追问，指出哪些连接需要源码证据。 | 对照文件/符号/行号；未找到不补造。 |
| 对象边界 | 这四个角色的边界可能混淆在哪里？不要假定同名类存在。 | 区分抽象与实际实现，审查来源和验证状态。 |
| 反例 | 请提示我遗漏的设备、Revision、工况、单位比较条件。 | 自己构造和解释四个反例。 |
| 状态一致性 | 针对服务器 A、未保存页面 B、未知导出源，哪些假设需核实？ | 列出状态、证据与静态核验方案，不声称已运行。 |
| 风险 | 我列出的风险有哪些未说明影响或验证方式？ | 自己决定优先级与负责人。 |

## B 实施 Prompt Map

| 阶段 | 提示词（接共同前缀） | 学员核验 |
|---|---|---|
| 流程 | 我的模拟询盘流程有哪些责任交接缺口？ | 依据输入与授权边界自己补充。 |
| 参数 | 我的表中哪些值缺来源、单位或工况？ | 返回原始摘录；不要把缺失内容当事实。 |
| 分类 | 哪些句子可能混淆事实、判断、假设和待确认？ | 逐项说明分类和来源。 |
| 异常 | 对我的澄清和升级路径提出两个追问。 | 保留冲突及权责，不自动选择。 |
| 邮件 | 只检查我的模拟邮件是否有暗示批准或缺少问题，不代写邮件。 | 学员自行修改；不发送。 |

## 通用记录模板

任务/日期：待填写；独立初稿链接：待填写；问题原文：待填写；AI 关键建议：待填写；质疑 1（建议、原因、核验、处理）：待填写；质疑 2（同前）：待填写；本人最终结论及证据：待填写；最高帮助等级 H0/H1/H2/H3：待填写；具体帮助：待填写。以 [能力等级与帮助记录](资料/能力等级与帮助记录.md) 为准：H2/H3 不能单独证明独立掌握，AI 完成主要成果为 H3；如独立考核中获得解题方向，转练习并另用新变体 H0 复现。
