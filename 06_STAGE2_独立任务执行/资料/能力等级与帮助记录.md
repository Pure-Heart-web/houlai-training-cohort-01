# 六级能力与帮助记录

按“成员 × 能力项”评价，每次记录任务、成果链接、测试或复核证据、帮助等级、结论和下一步。

| 等级 | 可观察表现与证据 | 前置和判断 |
|---|---|---|
| L0 观察 | 复述目标、步骤和至少一个待确认事项 | 起点；可全程指导 |
| L1 引导 | 按步骤完成局部操作，发现偏差时求助；留操作记录 | 完成 L0；允许详细提示 |
| L2 AI 协作 | 提出计划、使用 AI 并核查其输出；提交成果与帮助记录 | 完成 L1；H1–H3 均可学习 |
| L3 独立工作包 | 独立拆解、完成并验证明确范围的工作包，处理常见异常 | 完成 L2；一次达标练习及一次未预见变体 H0 独立复现，关键验收全通过 |
| L4 独立模拟交付 | 负责本岗位从澄清到交付、异常、交接和模拟验收 | 相关能力达 L3；完整模拟交付及含异常的新变体，以 H0 完成岗位核心判断；可进行明确的跨岗位协作 |
| L5 带教复制 | 观察、反馈并帮助他人独立完成 | 相关能力达 L4；提供带教记录及被带教者独立成果 |

H0：独立完成，AI 仅用于不影响解题方向的工具性查询；H1：方向性提问或提示，学员完成关键判断与实现；H2：AI 给出关键思路、规则、代码或明显纠错；H3：AI 完成主要成果，学员主要检查整理。记录本次最高等级和具体帮助；H2/H3 不能单独证明独立掌握。导师可以解释任务边界，但提供解题方向即如实记录帮助。若独立考核中得到提示，转为练习并另用新变体复现。

关键验收项全通过、结果可追溯、他人可复核、未知不编造，才算达标。当前仓库尚无完整 L4 案例或隐藏复现变体，不能用 CASE-001 的完成直接认定 L4。
